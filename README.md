## Repository Structure

```
sai-sri-ram-portfolio/
├── assets/                   # Images, icons, resume PDF
│   ├── images/               # Profile photo, project screenshots
│   ├── icons/                # Favicon
│   └── resume/               # Resume PDF
├── css/                      # Stylesheets
│   ├── tokens.css            # Colors, fonts, theme variables
│   ├── base.css              # Reset, typography, focus styles
│   ├── layout.css            # Container, header, mobile menu
│   ├── components.css        # Buttons, cards, status dot
│   └── sections/             # One file per section
│       ├── hero.css, about.css, projects.css, skills.css,
│       ├── experience.css, contact.css, case-study.css
│   └── responsive.css          # Breakpoints
├── js/                       # JavaScript modules
│   ├── data.js               # Projects, skills, ticker items
│   ├── render.js             # Builds project cards, skill rows
│   ├── theme.js              # Light/dark toggle
│   ├── navigation.js         # Mobile menu, active nav link
│   ├── reveal.js             # Fade-up on scroll
│   ├── router.js             # Case-study page routing
│   ├── theme-init.js         # Applies saved theme before first paint
│   └── route-init.js         # Hides home page on case-study URLs
├── content/                  # Synced GitHub READMEs (build-time)
│   ├── readmes/              # Rendered JSON + raw MD per project
│   └── raw/                  # Raw README markdown files
├── public/                   # Static assets for deployment
│   ├── _redirects            # Netlify/Cloudflare fallback
│   └── robots.txt
├── scripts/                  # Build utility scripts
│   ├── fetch-readmes.mjs     # Sync GitHub READMEs at build time
│   ├── lib/github.mjs        # GitHub API helpers
│   └── lib/markdown.mjs      # Markdown renderer with mermaid
├── vercel.json               # Vercel deployment config
└── vite.config.js            # Vite configuration with SPA fallback
```
